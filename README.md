# GlobeTrotter - Personal Travel Planning Application

GlobeTrotter is a modern, full-stack travel itinerary web application designed for personalized, organized, visual, and budget-aware travel planning.

## Viator Affiliate API Key Setup

To get a `VIATOR_API_KEY`, register at [Viator's Partner Program](https://www.viator.com/partner) → create an affiliate account → Basic API access is instant with no approval wait. Add your key to `backend/.env`:

```env
VIATOR_API_KEY=your_viator_affiliate_api_key
```
